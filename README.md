# PetroVision

## Petroleum Contamination Detection and Classification in Aquatic Environments Using Sensor Data and Computer Vision

PetroVision is a research-oriented software project focused on the detection
and classification of petroleum contamination in aquatic environments using
sensor-data machine learning and computer vision.

### Current Scope

The 7th-semester work focuses on:

- Sensor-data machine learning
- Computer vision
- CNN-based visual analysis
- Image segmentation
- Model comparison and evaluation
- Robustness analysis
- Interactive visualization
- Real-time webcam-based demonstration
- Research and literature analysis

### Primary Domain

Artificial Intelligence and Machine Learning

### Specialization

Computer Vision and Deep Learning

### Application Area

Environmental Monitoring

### Important Research Principle

Results reported by existing research will be clearly distinguished from
experiments and results produced by the PetroVision project.

No experimental accuracy, dataset, or performance result will be fabricated.

### Project Status
