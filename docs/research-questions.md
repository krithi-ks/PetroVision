# PetroVision — Research Questions

## Main Research Question

How can machine learning and computer vision be used to support the
detection and classification of petroleum contamination in aquatic
environments?

---

## Research Questions

### RQ1 — Sensor-Based Machine Learning

How do different machine-learning approaches perform for petroleum
contamination detection and classification using aquatic-environment
sensor data?

---

### RQ2 — Model Robustness

How robust are sensor-based machine-learning models to variations and
perturbations in the input data?

Potential investigations include:

- Training-set size
- Input noise
- Cross-validation
- Model stability

---

### RQ3 — Computer Vision

Can computer vision and CNN-based image segmentation identify and
localize visible petroleum-like contamination in aquatic images?

---

### RQ4 — Visual Quantification

Can image segmentation be used to estimate the visible proportion of
contamination within a selected image region?

The resulting value will represent image-based visible coverage and will
not be interpreted as petroleum volume, concentration, or thickness.

---

### RQ5 — Real-Time Visual Analysis

Can the computer-vision component be integrated into an interactive
webcam-based system for real-time visual analysis?

The webcam component will be treated primarily as a demonstration and
application interface unless sufficient independently labelled data is
available for quantitative evaluation.

---

### RQ6 — Complementary Information

What complementary information can sensor-based machine learning and
computer vision provide for petroleum contamination monitoring?

This question does not assume that the two modalities are automatically
better when combined.

Any multimodal integration will be considered only after the individual
components have been independently evaluated.

---

### RQ7 — Practical Deployment

What are the computational and practical considerations for developing
a lightweight petroleum-contamination analysis system?

Potential considerations include:

- Inference time
- Model size
- Computational requirements
- Dataset requirements
- Real-time operation
- Deployment constraints

---

# Research Boundaries

PetroVision will not claim that RGB computer vision alone can chemically
identify petrol, diesel, or other petroleum products.

Computer vision will be used to investigate visible appearance and
localization of contamination.

Image-based coverage will not be treated as a direct measurement of:

- Petroleum concentration
- Petroleum volume
- Spill thickness
- Chemical composition

Sensor-based conclusions will depend on the availability and quality of
legitimate labelled data.

The original dataset from the 2026 IEEE base paper will not be fabricated
if it is unavailable.

---

# Research Evidence Categories

Every research question will be supported using one or more of the
following:

### Literature Evidence

Findings reported by existing research.

### Dataset Evidence

Information obtained from legitimate publicly available or independently
collected datasets.

### Experimental Evidence

Results generated by PetroVision experiments.

### Demonstration Evidence

Observations from the interactive application that are not necessarily
quantitative scientific evidence.

These categories will remain clearly separated.

---

# Expected Research Contribution

The project aims to investigate a software-based framework that combines:

1. Sensor-data machine learning research
2. Computer vision
3. CNN-based segmentation
4. Visible contamination localization
5. Interactive real-time visualization

The project will experimentally evaluate these components rather than
assuming a particular algorithm or modality is superior.
